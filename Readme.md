# Be VLiver (仮)

**ジャンル**: VLiverシミュレーション / 育成 / アドベンチャー / RPG  
**プラットフォーム**: PC（Windows/Mac）  
**プレイ時間**: 約2時間（1周想定）

---

## 🎮 ゲーム概要

あなたは病床の姉に代わり、VLiver（バーチャルライバー）活動を始めることに。
登録者数を増やし、無事姉の退院を迎えることができるのか…！？

ターン制の育成＋配信＋ストーリーパートで構成された、挑戦と成長の物語。


## 📦 プロジェクト構成

```
Assets/
├── Live2D/             # Live2D CubismモデルとSDK
├── Scripts/            # ゲームロジック
├── Scenes/             # Unityシーン
├── Resources/          # 各種アセット（画像/音声）
ProjectSettings/         # Unityプロジェクト設定
Packages/                # 使用中のUnityパッケージ
README.md                # 本ファイル
.gitignore               # Git除外設定
```


## 🔧 使用技術

- Unity（ゲームエンジン）
- Live2D Cubism SDK for Unity（アバター表示）
- VTube Studio連携予定
- Visual Studio Code（エディタ）
- Git + GitHub（バージョン管理）


## 🚀 遊び方（仮）

- アバターを育成（スキル選択・パラメータアップ）
- 配信コンテンツを選んでバズを狙う（雑談/ゲーム配信/歌枠）
- ストーリーパートで物語を進行
- 最終的にエンディングを目指す
